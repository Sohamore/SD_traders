01   Introduction

Introduction to the Website

SD Traders is a multi-page demonstration storefront for electric and remote-controlled toys. It introduces the store, presents a selection of products, and gives visitors basic ways to place an order, view a cart, and share feedback.

Project purpose
To provide a simple, navigable online catalog and demonstrate common storefront interactions using a lightweight web stack.

What visitors can do

  • Explore the home page, store information, product catalog, and gallery.
  • Review listed products and prices, then add products to the cart or open an order form.
  • Submit a customer rating and feedback through the feedback page.
  • Browse contact and review information through the site navigation.

How the demonstration works

The main pages are static HTML documents styled by a shared stylesheet. JavaScript provides front-end interactions, including order-form validation and browser-local cart data. A small Python development server serves the files and includes basic POST handling for PHP-style endpoints. The project also contains separate Python and C++ command-line calculator examples.

This is a demonstration project: the included pages do not describe a production payment, shipping, inventory, or database system.

02   Implementation

Technologies Used

HTML5Page structure, navigation, catalog content, forms, and semantic sections.
CSS3Shared visual styling, responsive layouts, and grid/flex-based page sections in css/style.css.
JavaScriptClient-side interactions and validation; cart data is stored in browser localStorage. Main scripts are in js/script.js and js/cart.js.
Python 3server.py uses the standard-library HTTP server modules to serve project files and handle selected form POST requests.
C++tools/toy_discount.cpp demonstrates a tiered toy-order discount calculation.
Python utilitytools/toy_calculator.py is a separate command-line toy cost calculator.

Key project files

The three page captures below are the home page (index.html), catalog (products.html), and order form (order.html). Their shared styles and client-side behavior are maintained in the CSS and JavaScript files listed above.

The site can be served locally by running python server.py from the project folder, then opening the local address printed by the server.
